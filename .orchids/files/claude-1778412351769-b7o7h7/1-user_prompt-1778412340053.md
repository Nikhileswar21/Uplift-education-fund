Design and build a premium, non-basic UI for a 5-page education charity website using Next.js and Tailwind CSS. I only need the frontend UI, not backend functionality. The website should look like a polished, jury-ready product for an international nonprofit, with a modern, minimal, emotionally credible design that feels custom-made and not like a generic charity template. Nonprofit UI should keep the donate action highly visible, use clear navigation, and stay mobile-first with clean readable layouts.

Pages required:

Home Page

Programs Page

Program Detail Page

Donate Page

Impact / About Page

Brand concept:

Name: Uplift Education Fund

Purpose: Help underserved children through scholarships, school kits, digital learning access, and community education programs

Tone: Trustworthy, warm, premium, human-centered, impactful

Audience: Donors, supporters, volunteers, and people discovering the nonprofit for the first time

Core instruction
Do not make the UI basic, repetitive, or template-like. Avoid generic SaaS sections, flat card grids with no hierarchy, or plain NGO layouts. Make it feel like an award-quality nonprofit website with strong visual direction, thoughtful spacing, elevated typography, layered sections, and a smooth donation-focused journey. Donation UX should be obvious, mobile-friendly, and low-friction, with clear visual emphasis on the primary CTA.

Design direction
Create a visually rich but restrained interface:

Premium minimalist aesthetic

Warm neutral background, soft ivory or light beige base

Deep teal, forest green, or muted blue accent for CTAs

Strong editorial typography with large expressive headings and clean body text

Asymmetrical but balanced layouts

Layered sections with refined cards, soft shadows, subtle gradients only where tasteful

Micro-interactions, hover states, scroll reveal effects, animated counters, and elegant transitions used carefully

High-end visual hierarchy that feels custom designed, not generated

Visual quality rules
No basic hero section with centered text and one button only

No generic 3-card feature section that looks copied from a startup landing page

No default Tailwind-looking UI

No overused purple-blue gradients or glowing blobs

No boring white background with simple stacked sections

No cheap-looking donation form

Every page should have at least one strong visual composition moment

The UI should feel like Dribbble/Behance quality but still realistic for a nonprofit site. Visual inspiration platforms can help define this higher-quality aesthetic direction.
